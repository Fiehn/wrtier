        Allow access to your files

        Wrtier keeps your Works as files in a folder you choose, such as one Syncthing syncs. To read and write them, it needs All files access.

        Turn on “Allow access to manage all files” for Wrtier, then come back here.

        If the switch is greyed out: open App info, tap ⋮ in the top corner, choose “Allow restricted settings”, then try again.

        Allow installing updates

        To install an update, Wrtier hands it to Android's installer. Android lets it do that only once you allow it to install unknown apps.

        Turn on “Allow from this source” for Wrtier, then come back here. Android still asks before installing anything.

                                This deletes Wrtier from this PC, with what it keeps here for this device: its ID, open tabs, window position, Syncthing connection and the editor's cache.
